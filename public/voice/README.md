# The spoken library

Generated by `scripts/voice.py`, not by hand.

Each recording is one fragment, named for the first sixteen hex characters of
its SHA-1 — so identical fragments across two texts share a file, and editing a
text regenerates only the lines that changed. `src/lib/voice.ts` derives the
same name in the browser, which is why the two must not drift apart.

`manifest.json` exists so the client can tell "this fragment has no recording"
from "nothing is recorded at all". Without it, a browser that also has no
system English voice would show a working exercise that never makes a sound.
It counts only the sixteen-character files: `sample-*` and `compare-*` are
auditions, not library.

    python3 scripts/voice.py --samples                       # one line per voice
    python3 scripts/voice.py --provider openai --voice nova  # the library
    python3 scripts/voice.py --provider groq --limit 5       # a taste first

Resumable: rerun it after an interruption and it picks up what is missing.

## Providers

`openai` (tts-1, $15/M characters) is the default. `groq`
(canopylabs/orpheus-v1-english, $22/M) sounds good and rations hard — a hundred
requests per twenty-four hours, which is fifty days for this library. Measured,
not read off a page: every call pushes the reset timer out by 14m24s.
