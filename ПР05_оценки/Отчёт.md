ПРАКТИЧЕСКАЯ РАБОТА № 05

Построение простой информационной модели
(система «Мои оценки за четверть»)


────────────────────────────────────────────────
1. ПОСТАНОВКА ЗАДАЧИ
────────────────────────────────────────────────

Система — моя успеваемость за четверть: школьные предметы и полученные
по ним оценки. Цель модели — видеть, какая оценка выходит по каждому
предмету и что нужно исправить до конца четверти.

Вопросы модели:
    1. Какой средний балл по каждому предмету?
    2. Какая итоговая оценка выходит сейчас?
    3. По каким предметам оценка «на грани»?
    4. Сколько пятёрок нужно получить, чтобы выйти на нужный средний балл?

Существенные свойства: предмет, дата, оценка, вид работы.
Несущественные (отброшены): кабинет, номер урока по расписанию, домашнее
задание, настроение учителя.


────────────────────────────────────────────────
2. ВЫБОР ТИПА МОДЕЛИ
────────────────────────────────────────────────

Выбрана знаковая табличная модель. Записи однотипны и связаны
«один ко многим»: один предмет — много оценок. Задача требует расчётов
(средние, количество, прогноз), а в таблице они выполняются формулами
и пересчитываются сами при добавлении новой оценки. Графическая модель
считать не умеет, поэтому диаграмма добавлена только для наглядности.


────────────────────────────────────────────────
3. СТРУКТУРА МОДЕЛИ
────────────────────────────────────────────────

Таблица «Предметы» (справочник, 8 записей):
    Код | Предмет | Учитель

Таблица «Оценки» (журнал, 32 записи):
    № | Дата | Код | Оценка | Вид работы
    + расчётное поле: Предмет

Связь: поле «Код» журнала ссылается на ключ справочника, поэтому название
предмета хранится один раз и подставляется автоматически.

Лист «Модель» — параметры: нужный средний балл (4,5), начало четверти,
сегодняшняя дата. Лист «Итоги» — расчёты и диаграмма.


────────────────────────────────────────────────
4. ВВОД ДАННЫХ
────────────────────────────────────────────────

Введены оценки с 02.09.2026 по 22.09.2026 — 32 оценки по восьми предметам,
по четыре на каждый. Виды работ: устный ответ, самостоятельная,
контрольная, диктант, тест, доклад, проект.


────────────────────────────────────────────────
5. ЛОГИКА МОДЕЛИ (формулы)
────────────────────────────────────────────────

Подстановка предмета из справочника:
    =IFERROR(INDEX(Предметы!$B$2:$B$9;MATCH($C2;Предметы!$A$2:$A$9;0));"")

Средний балл по предмету:
    =ROUND(SUMIF(Оценки!$C$2:$C$33;"П1";Оценки!$E$2:$E$33)/$B9;2)

Итоговая оценка:      =ROUND($C9;0)
Количество пятёрок:   =COUNTIF(Оценки!$E$2:$E$33;5)

Сколько пятёрок нужно добрать до нужного среднего:
    =IF($C9>=цель;0;ROUNDUP(($B9*(цель-$C9))/(5-цель);0))

Статус предмета:
    =IF($C9>=цель;"цель достигнута";IF($C9>=4;"на грани";"нужно подтянуть"))


────────────────────────────────────────────────
6. ИССЛЕДОВАНИЕ МОДЕЛИ
────────────────────────────────────────────────

Общие показатели:
    Оценок получено ........... 32
    Средний балл .............. 4,22
    Пятёрок ................... 11
    Четвёрок .................. 17
    Троек ..................... 4

По предметам:

    Предмет            Средний   Итог   Пятёрок до 4,5   Статус
    Информатика          4,75      5           0         цель достигнута
    Английский язык      4,75      5           0         цель достигнута
    Литература           4,50      5           0         цель достигнута
    История              4,50      5           0         цель достигнута
    Алгебра              4,00      4           4         на грани
    Геометрия            3,75      4           6         нужно подтянуть
    Физика               3,75      4           6         нужно подтянуть
    Русский язык         3,75      4           6         нужно подтянуть

Чтобы выйти на средний балл 4,5 по всем предметам, нужно добрать
22 пятёрки — за оставшуюся часть четверти это нереально, значит
цель надо ставить по отдельным предметам, а не по всем сразу.

Эксперимент: если в параметрах поставить нужный средний балл 4,0
вместо 4,5, статус «нужно подтянуть» остаётся только у трёх предметов
с баллом 3,75, а требуемое число пятёрок падает с 22 до 3.


────────────────────────────────────────────────
7. АНАЛИЗ РЕЗУЛЬТАТОВ
────────────────────────────────────────────────

Модель адекватна: средние баллы совпадают с расчётом вручную,
а итоговая оценка получается той же, что ставит учитель округлением.

Ограничения модели:
  • все оценки имеют одинаковый вес, хотя контрольная в реальности
    важнее устного ответа — исправляется добавлением столбца «вес работы»
    и переходом на СУММПРОИЗВ вместо среднего;
  • спорный балл 4,50 округляется вверх до 5, а учитель в такой ситуации
    смотрит на оценки за контрольные, чего модель не учитывает.

Выводы по системе: половина предметов уже вышла на нужный уровень,
проблемные — геометрия, физика и русский язык, по ним одинаковый
средний балл 3,75 и до «пятёрочного» уровня далеко; реальная задача
на оставшуюся четверть — подтянуть эти три предмета хотя бы до 4,5,
а не гнаться за средним по всем сразу.


────────────────────────────────────────────────
ОТВЕТЫ НА ВОПРОСЫ
────────────────────────────────────────────────

1. Какую реальную систему можно смоделировать?
Любую систему из однотипных объектов со связями: успеваемость,
расписание уроков, домашний бюджет, склад, тренировки, коллекцию игр.
Главное — чтобы была цель моделирования, то есть вопрос,
ради ответа на который модель строится.

2. Какие свойства этой системы будут важны для модели?
Только влияющие на ответ: предмет, дата, оценка, вид работы.
Кабинет, номер урока и фамилия соседа по парте для цели «понять,
какая оценка выходит» не нужны — лишние свойства усложняют модель,
не повышая точности.

3. Какие инструменты можно использовать для построения модели?
Электронные таблицы (Excel, LibreOffice Calc, Р7-Офис), базы данных
(Access, SQLite), языки программирования (Python), редакторы схем
(draw.io). В работе выбраны электронные таблицы — их хватает
для двух связанных таблиц, расчётов и диаграммы.


ВЫВОД: построена и исследована простая табличная информационная модель
успеваемости; модель считает средний балл и итоговую оценку по каждому
предмету, показывает проблемные предметы и оценивает, сколько пятёрок
нужно добрать до цели.
